# ⚡ 電磁気学 用語クイズアプリ（Supabase × 外部API）

## 📌 アプリ概要
本アプリは、**大学の電磁気学のテスト勉強を目的とした学習用クイズアプリ**です。  
電磁気学で頻出する専門用語について、**ヒントをもとに用語を当てるクイズ形式**で学習できます。

データベースには **Supabase** を使用し、  
ヒント生成には **無料で利用できる外部API（Wikipedia API）** を利用しています。

---

## 🎯 主な機能

### 1️⃣ 電磁気学用語クイズ機能
- Supabase の `terms` テーブルに保存された用語から、ランダムに1問出題
- ヒントを読んで、用語名を入力して回答
- 正解・不正解を即時に判定

### 2️⃣ 外部APIを利用したヒント取得
- **Wikipedia API** を利用して、電磁気学用語の説明文を取得
- 教科書的な定義に近い説明をヒントとして表示
- 外部Web APIを利用しているため、本アプリは「API利用」の条件を満たしています

### 3️⃣ 次の問題へ進む機能
- 「次の問題」ボタンを押すことで、別の用語が出題される
- 繰り返し学習が可能
