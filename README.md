# 単語4択学習アプリ

## 概要
このアプリは、単語を4択クイズ形式で学習できるWebアプリです。
単語登録、テスト、復習、履歴確認ができます。

## 主な機能
- 単語登録
- 4択クイズによるテスト
- 間違えた問題だけの復習モード
- 解答履歴の確認
- Supabaseによるデータ保存

## 使用技術
- Python
- Streamlit
- Supabase

## アプリURL
https://supabase-word-quiz-nv95kql2tp8oftyub6kd44.streamlit.app/

## 工夫した点
- 復習モードで苦手な単語だけ学習できる
- 履歴を保存して学習の振り返りができる
