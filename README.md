# 単語4択学習アプリ（Supabase版）

## 概要
本アプリは、単語学習を目的とした4択クイズ形式の学習アプリである。
Streamlit を用いて Web アプリとして実装し、
データベースには Supabase（PostgreSQL）を利用している。

---

## 主な機能
- 単語と意味、誤答選択肢の登録
- 登録された単語を用いた4択クイズ
- 正解・不正解の判定表示
- 学習履歴の保存
- 正答率の集計

---

## 使用技術
- Python
- Streamlit
- Supabase（PostgreSQL）
- GitHub
