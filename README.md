# Supabase Word Quiz App

英単語を4択クイズ形式で学習できる Web アプリです。  
Streamlit と Supabase を用いて作成しています。

## アプリ概要

このアプリは、英単語を登録し、  
4択クイズとして出題することで学習できるアプリです。

大学の授業課題として、  
Web アプリ開発とデータベース連携の理解を目的に制作しました。

## 主な機能

- 英単語と意味の登録
- 4択クイズの出題
- 正解・不正解の表示
- Supabase を用いたデータ保存
- Streamlit による Web アプリ表示

## 使用技術

- Python
- Streamlit
- Supabase
- GitHub
